# 🔐 Task 6 – Password Strength Evaluation

## 🎯 Objective
To understand what makes a password strong, test it using online tools, and learn password security best practices.

## 🧩 Passwords Tested
| Password | Strength | Crack Time | Feedback |
|-----------|-----------|------------|-----------|
| leodas982 | 30% | Instantly | Too short; lacks symbols & uppercase |
| zenin@97866 | 55% | A few hours | Add uppercase letters |
| ZenIn@#890 | 80% | Centuries | Strong combination |
| ZEninMUst@ng088!#5 | 100% | Millions of years | Excellent password |

## 🧠 Insights
- Use **12–16+ characters**
- Mix letters, numbers, and special characters
- Avoid names, patterns, or dictionary words
- Enable **Multi-Factor Authentication**
- Prefer **passphrases** for easy memory and strength

## 🧨 Common Password Attacks
| Attack | Description | Prevention |
|--------|--------------|-------------|
| Brute Force | All combos are tried | Long complex passwords |
| Dictionary | Uses wordlists | Avoid words, add symbols |
| Phishing | Fake login pages | Verify site & MFA |
| Keylogging | Records keys | Secure systems, MFA |
| Credential Stuffing | Leaked passwords reused | Use unique passwords |

## 📚 Conclusion
Password complexity directly affects security.  
Stronger passwords with randomness and length protect better against brute-force and dictionary attacks.  
Always combine them with **MFA** for maximum protection.
